In order to allow other people to record in your server, create a role that will act as an **access role** which allows anyone with that role to use Craig to record. You need the "Manage Server" permission to configure access roles.

You can use the `/server-settings access-role` command to add and remove access roles.

<Image src={accessRoleAdd} alt="Usage of the `/server-settings access-role add` command" style="border-radius: 0.75rem; margin-bottom: 1.5rem;" />

You can view the access roles with `/server-settings view`.

<Image src={serverSettingsView} alt="Usage of the `/server-settings view` command" style="border-radius: 0.75rem; margin-bottom: 1.5rem;" />
